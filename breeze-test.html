Breeze ASR 25 本機辨識測試

辨識在這台電腦上進行，不需要金鑰，聲音不會送出。右欄同時顯示 Chrome 雲端辨識作為對照。

設定

第一次需要下載模型，依網路速度約數分鐘到十多分鐘；之後會存在瀏覽器裡，不必重新下載。

先把直播開在另一個 Chrome 分頁，按「開始」後選那個分頁，並勾選「同時分享分頁音訊」。

檔案只會由 Breeze 辨識，沒有 Chrome 對照。

尚未開始。每一段會顯示「聲音長度」與「辨識花費時間」，用來判斷這台電腦跟不跟得上直播。

Breeze ASR 25（本機）

使用順序：

  1. 用電腦版 Chrome 開啟本頁。
  2. 按「下載並載入模型」，等到顯示「模型已就緒」。
  3. 把立院直播開在另一個分頁，回到本頁按「開始」。
  4. 約每 20 多秒出一段文字，比較這一欄與右欄的差異。
